# discord-hlsoundbot
discord.py bot that plays and strings together sounds from half-life using sox.
requires the sounds from half-life, everything should ideally be encoded the same way.

honestly you could probably use it for any sounds they just have to be encoded the same way.

usage:
v.tts [ttsType] [message] | v.tts vox freeman is kill

or

v.tts mixed [ttsType:message] | v.tts mixed vox:freeman vox:is hgrunt:shit!.


**requires a local version of ffmpeg and sox in path**
